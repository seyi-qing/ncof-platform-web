# NCOF Platform Web 2.0.0

Next.js frontend for the NCOF Platform API (v1.7.x).

## Setup

```bash
npm install
npm run dev
```

## Environment

```
NEXT_PUBLIC_API_URL=https://ncof-api.vercel.app/api/v1
```

## Deploy

See `DEPLOY.md`. Connect this repository to Vercel and set the environment variable above.

## Stack

- Next.js 15
- React 19
- TypeScript
- Lucide icons
